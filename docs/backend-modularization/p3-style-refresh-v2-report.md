# P3 追加修改 v2：深色懸浮卡片風格

淺色版你反饋還是土，這輪整個換成深色風格，參考你附的那張深色 SaaS 儀表板截圖——但那張圖是完整的專案管理後台（甜甜圈圖表、行事曆、團隊狀態列表），跟我們這裡「四個模組的啟動器」性質不一樣。借用的是它的**視覺語言**：深色底、懸浮圓角卡片、飽和色塊圖示、簡潔留白，套在我們自己的排版跟四個功能上，配色數值、卡片比例、陰影畫法都是自己抓/自己算的。

## 這輪改了什麼

1. **主題從淺色（cosmo）換成深色（superhero）**：`superhero` 是 ttkbootstrap 內建主題，深藍灰底（不是純黑）、主色是飽和藍，比第一版的 `darkly`（我們在 P1 用過，你可能還記得那個偏灰黑）更接近你參考截圖的深藍色調。

2. **卡片改成「懸浮陰影」畫法**：每張卡片底下多畫一層往右下偏移的深色色塊，模擬網頁 `box-shadow` 的立體浮起效果（Tkinter 沒有陰影這個功能，這是最常見的克難畫法——多畫一層暗色矩形在後面）。卡片本體顏色比頁面底色亮一階，滑鼠移上去再亮一點、邊框同時變成該模組的主題色，給清楚的可點擊提示。

3. **圖示徽章從圓形改成圓角方形**：比較貼近深色後台常見的色塊圖示畫法（你截圖裡 Task Overview / Active Projects 那些色塊也是方形系）。

4. **AI 代理卡片的配色從灰色（SECONDARY）換成藍色（PRIMARY）**：深色底下灰色圖示徽章存在感太弱，換成主題藍之後四張卡片變成「綠／青／橘／藍」，彼此對比更清楚。

5. **新增「🟢 系統運作中」狀態膠囊標籤**：放在頂部品牌區下方，膠囊形狀（圓角矩形，角半徑貼齊高度）+ 淡色調底（該模組主題色跟頁面底色混出來的淡色，不是整塊塗滿），呼應深色後台常見的狀態提示做法。

6. **所有顏色都是從主題色盤動態算出來的，沒有寫死的色碼**：卡片本體「比頁面底色亮一階」、陰影「比底色暗一階」、說明文字「主文字色往底色混成灰階」——這些都是相對於 `colors.bg`/`colors.fg` 現場計算，不是針對深色主題另外寫一份色碼。好處是：如果你之後想再換成 `darkly`、`cyborg`、`solar` 之類 ttkbootstrap 內建的其他深色主題，只要改 `__main__` 那行主題名稱字串，卡片的顏色會自動跟著調整，不用每個主題重新設計一次色碼，也不會出現「卡片背景跟外框對不起來」的色塊接縫問題。

## 怎麼驗證的

打樁測試這次額外補了「卡片本體 vs 陰影層 vs 圖示徽章」三層圓角矩形各自的顏色檢查，以及新的狀態膠囊：

- 確認每張卡片正確畫出 3 個圓角矩形（陰影層、卡片本體、圖示徽章），圖示徽章顏色正確對應到「綠／青／橘／藍」四個色系（含這次 AI 卡片從灰換成藍）。
- 模擬滑鼠移入卡片，確認卡片本體底色變亮、邊框變成該模組主題色；移開後確認兩者都恢復原狀。
- 確認頂部「🟢 系統運作中」狀態膠囊正確畫出。
- 模擬點擊卡片（「員工帳號管理」「營運狀態與尾隨監控」分別測），確認正確開啟對應視窗。
- 重跑時鐘、底部系統資源列、AI 代理設定＋RAG 啟動流程、QR 註冊視窗、關閉主視窗，確認跟前幾輪的行為一致，沒有連帶壞掉。

全部通過後才把 `backend_main.py` 用你電腦上目前的修改時間當版本鎖寫回去。

## 下一步

這次風格改動幅度比較大（換主題、改陰影畫法、改圖示徽章形狀），建議你實際打開一次看看效果，尤其是：懸浮陰影在真實螢幕上的立體感夠不夠明顯、四個顏色的對比看起來順不順眼、狀態膠囊的大小位置合不合適。如果還有哪裡想調（例如卡片再大一點、字體再大一點、要不要幫每張卡片也加一條類似截圖裡的進度條/數字），都可以直接告訴我，這個階段我們可以繼續來回調整，不急著往下一步（P4）走。
